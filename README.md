# PECS Eye v1

視線・タッチ・マウスポインタで絵カードを選び、文を作って読み上げる試作Webアプリです。

## 使い方
1. `index.html` をブラウザーで開く。
2. カードをタップ、クリック、またはポインタをカード上に一定時間置いて選択する。
3. 「わたしは」「ほしい」を必要に応じて追加する。
4. 「つたえる」で端末の音声合成により読み上げる。
5. 「先生用設定」で注視時間・カードサイズ・カード追加を設定できる。

## 視線入力について
- 外部視線装置がマウスポインタを操作できる場合は、カード上にポインタを置くことで注視決定を使えます。
- Webカメラ視線推定は試験機能です。WebGazerをネットワークから読み込むため、初回およびWebカメラ視線利用時には通信が必要です。
- Webカメラ推定は専用の視線入力装置ほど正確ではありません。

## オフライン
カード選択、文づくり、読み上げ、設定、追加カードの保存は基本的に端末内で動きます。Webカメラ視線推定だけは外部ライブラリ読込のため通信が必要です。

## データ
追加カードや設定はブラウザーの localStorage に保存されます。別端末・別ブラウザーには自動で引き継がれず、ブラウザーのデータ消去で失われることがあります。
